# Фронтенд — журнал правок интерфейса

Лендинг центра **Արևէ**, Абовян. Список замечаний по интерфейсу: что не так,
где и в каком оно состоянии. Пока пуст — интерфейса ещё нет. Формат задан
заранее, чтобы записи не расползались.

---

## Как пользоваться

Одна запись — одно замечание. Запись живёт в разделе по состоянию и
переезжает между разделами, а не переписывается заново.

```markdown
### UI-001 · Короткое название
- **Где:** `src/pages/Home/ui/HomePage.tsx` (или «главная, блок отзывов»)
- **Что не так:** что видит пользователь
- **Ожидается:** как должно быть
- **Как повторить:** шаги, ширина экрана, тема, язык — если зависит
- **Заметил:** дата
- **Состояние:** открыто | в работе | сделано | отклонено
```

Номера сквозные и не переиспользуются.

## Что стоит проверять

Замечания сюда попадают из проверки по этому списку:

- **Ширина экрана** — от ~360 px до широкого монитора; горизонтальной прокрутки
  у страницы быть не должно.
- **Тема** — светлая и тёмная, включая системную настройку;
  при загрузке страницы тема не мигает.
- **Язык** — самый длинный из переводов не должен ломать вёрстку;
  `<html lang>` меняется вместе с языком.
- **Состояния** — загрузка, ошибка, пусто, очень длинный текст.
- **Формы** — текст ошибки поля, повторная отправка, отправка с пустыми полями.
- **Клавиатура** — обход по Tab, видимый фокус, закрытие по Escape.
- **Кнопки без текста** — `aria-label` на месте.

## Что проверять именно здесь

Особенности этого лендинга:

- **Армянский текст.** Шрифты Noto Armenian загрузились, а не подменились
  системным; армянские слова длинные — заголовок hero и подписи кнопок не
  разъезжаются; переносы выглядят прилично.
- **Якорная навигация.** Каждая ссылка меню ведёт в свою секцию; заголовок
  секции не уезжает под липкую шапку.
- **Бургер-меню.** Закрывается по Escape и после перехода по ссылке; фокус не
  остаётся под закрытым меню. (В исходном лендинге меню на чекбоксе — в проекте
  оно на состоянии.)
- **Три карусели** — фото, отзывы, питание. Стрелки работают с клавиатуры;
  автопрокрутка останавливается при наведении и при фокусе; `prefers-reduced-motion`
  выключает автопрокрутку.
- **Форма заявки.** Ошибка телефона понятна на армянском; после успешной
  отправки видно, что заявка ушла; повторное нажатие не отправляет дубль;
  ответ сервера при ошибке показывается по `code`, а не сырым текстом.
- **Фотографии.** Не прыгает вёрстка при загрузке (размеры заданы); `alt`
  осмысленный, а не «Նկար 1».
- **Заглушки.** Адрес `[ձեր հասցեն]`, телефон `+374 XX XXX XXX`, место под
  карту — до запуска должны исчезнуть. Пока живы, это не замечание, а
  пункт плана (этап 10).

## Не сюда

- Нарушения архитектуры — их находит `npm run check:arch`, они чинятся сразу,
  а не заводятся записью.
- Ошибки серверной логики — журнал бэкенда в репозитории **areve-backend**.
- Новая функциональность — `docs/project-plan.md`.
