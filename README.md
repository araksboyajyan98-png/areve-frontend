# areve-frontend

Лендинг центра детской занятости «Արևէ» (`արև` — солнце, `է` — сущность),
город Абовян. Дети 1,5–6 лет, полный и неполный день.

Задача сайта одна: родитель понимает, подходит ли ему центр, и оставляет заявку.

Серверная часть — в репозитории **areve-backend**.

## Стек

React 19 · TypeScript · Vite 8 · Tailwind 3 · react-router-dom 7 ·
react-hook-form + zod · i18next. Архитектура — Feature-Sliced Design.

## Запуск

Нужен Node ≥ 22.

```bash
npm install
cp .env.example .env
npm run dev          # http://localhost:5173
```

Сайт умеет работать **без сервера**: поставьте `VITE_USE_MOCKS=true` в `.env` —
форма будет отвечать как настоящая, но никуда не отправлять. Так можно смотреть
и править интерфейс, не поднимая бэкенд и базу.

Порт 5173 закреплён (`strictPort`). Если он занят, Vite не переедет на соседний,
а выйдет с ошибкой — это намеренно: порт прописан в `CORS_ORIGINS` бэкенда,
и тихий переезд сломал бы отправку формы.

## Проверки

```bash
npm run check    # архитектура, типы, стиль
npm test         # договор с бэкендом
npm run verify   # всё вместе
```

`npm run check` запускается автоматически перед каждым коммитом.

**Архитектурные правила здесь не советы — их проверяет `tools/check-fsd.cjs`:**
импорт вверх по слоям, обход чужого `index.ts`, хук вне `model/`, компонент вне
`ui/`, мёртвый код. Проверка должна быть зелёной после каждой правки.
